# Phosphor test fixtures (`*.phfx`)

Generated by the Phosphor reference script, never edited by hand:

    python tools/waveform_test_signals.py waveform-tests     # Q2-Q9 WAVs (not committed)
    uv run tools/phosphor_waveform.py --fixtures src/test/phosphor --signals-dir waveform-tests

Regeneration is byte-identical (checked with `cmp`). The inputs are 0.2 s excerpts of the
synthetic test-signal WAVs, so no real audio is committed. Each file is one excerpt, treated
as a complete track starting at frame 0. C++ tests find them through
`getTestDir().filePath("phosphor/<name>.phfx")` (the test data folder is `src/test`).

Used by the analyzer test (tiers, color track) and the lane model test (lane cases).

## Container

All numbers are little-endian.

    "PHFX"            4 bytes magic
    u32               version (1)
    section*          until end of file

    section = char[4] tag, u32 payload size, payload

| Tag | Payload |
|---|---|
| `INPT` | `u32 rate, u32 channels (1 or 2), u32 frames`, then `int16` samples, interleaved. `channels = 1` means L = R. |
| `TIER` | `u32 N, u32 count`, then `int16 values[count]`. One per N = 4, 8, 16, 32. |
| `COLR` | `u32 block_frames, u32 block_count`, then `uint16 levels[block_count][3]` (R, G, B). |
| `LANE` | see below; zero or more |

The section order is `INPT`, `TIER` x4, `COLR`, `LANE`*.

### Sample buffer (`TIER`)

- Mono sum: `mono = floor((L + R) / 2 + 0.5)` on the int16 values, so ties round up. Clipped to
  int16. (Mixxx floats: scale by 32768 first.)
- Full (N = 1) is the mono sum itself and is not stored.
- N > 1: the mono sum is cut into blocks of N samples (the last block may be shorter and keeps its
  own length). Each block yields 2 values, its minimum and maximum **in the order they first
  occurred** (the minimum first if both are at the same index, which only happens when the block is
  constant). `count = 2 * block_count`.
- Point times, used by the lane model: block `k` of length `n` gives its first value the time
  `k*N + n/4` and its second `k*N + 3n/4` (in frames). For N = 1, sample `i` is at time `i`.

### Color track (`COLR`)

- `block_frames = round(rate / 1000)` (44 at 44.1 kHz), `block_count = frames / block_frames`
  (rounded down).
- Filters: three linear-phase FIR filters. `M = 2 * round(4096 * rate / 44100 / 2)` taps (4096 at
  44.1 kHz). Design: `g_c(f) = unit_table_c(f)^(1/0.35)` on the M-point rfft grid
  `f_k = k * rate / M`, where `unit_table_c` is research section 8.3's table, interpolated per
  channel on log frequency with `f` clamped to 21 Hz..18.5 kHz, then each frequency's RGB vector
  normalised to length 1. `h = roll(irfft(g, M), M/2) * hann`, `hann[n] = 0.5 - 0.5 cos(2 pi n / M)`.
  Applied by overlap-add and delay-compensated by M/2 (zero-phase).
- Level per block: `peak` = max |filtered sample| (input scaled to [-1, 1)) in the block;
  `level = peak^0.35`; then one-pole follower per channel, `y += (x - y) * (1 - exp(-dt / tau))`
  with `dt = 1 ms` (`block_frames / rate`), `tau = 5 ms` when rising and
  `350 / 180 / 40 ms` (R / G / B) when falling. Red is then max'ed with the same follower run
  backwards over the track (rise 5 ms, fall 120 ms).
- Stored: `round(level * 65535)`, clipped to 0..65535.

### Lane case (`LANE`)

    u16 name_length, char name[name_length]            (UTF-8)
    u32 tier_n                                          1 = Full, else a TIER buffer
    f64 position_frames                                 frame under the play marker
    f64 px_per_bar, f64 bpm (0 = none, treated as 120)
    f64 playhead_x                                      column of the play marker
    u32 width, u32 height                               columns, lane rows
    u32 window_milli_columns                            shape window x 1000 (2000 = 2 columns)
    u8  status[width]                                   0 outside the track, 1 signal, 2 digital silence
    i32 row_min[width], i32 row_max[width]              outline rows (0 = top), 0 when outside
    f32 levels[width][3]                                band levels 0..1, R G B
    f32 density[width][height]                          column-major: column x, rows 0..height-1

Definitions (the C++ lane model must match):

- Samples per column `spc = rate / (px_per_bar * bpm / 240)`. Column `x` is centered on frame
  `c = position + (x + 0.5 - playhead_x) * spc`.
- Window: points whose time lies in `[c - w*spc/2, c + w*spc/2]` (w = window columns), widened to
  always include the point at or before `c` and the next one. Clipped to the buffer. Fewer than 2
  points: status 0, all outputs 0.
- Window snapping: when the window is at least 32 frames wide (`w*spc >= 32`), its edges snap
  outward to multiples of 16 frames, `[floor((c - w*spc/2) / 16) * 16, ceil((c + w*spc/2) / 16) * 16)`
  (upper edge exclusive), in every tier, Full included. Blocks are aligned to the frame index from
  the start of the track, so every tier sees the same whole blocks and the outline is identical
  at all tiers. Below 32 frames (deepest zoom) the window is not snapped and tiers may differ.
- Rows: `rowOf(v) = clip(floor(center + v / 32768 * half + 0.5), 0, height - 1)`,
  `center = (height - 1) / 2`, `half = 0.8 * height / 2` (positive values go down). Use `double`.
  `row_min`/`row_max` are the extremes over the window's points. Status 2 if every point is 0.
- Density: for each pair of consecutive points the segment crosses the rows between their rows
  (inclusive, `r` rows); each gets `dt / r`, `dt` being the time between the two points. A row's
  hits are the sum. `density = hits / (t_last - t_first) * height / 2`. For N = 1, `dt = 1`.
- Levels: the `COLR` levels / 65535, linearly interpolated at `u = c / block_frames - 0.5`
  (clamped to the first and last block). Zero for status 0.
- Tolerances for the tests: outline rows exact, status exact, density within 1/255 per row,
  levels within 1 %.
